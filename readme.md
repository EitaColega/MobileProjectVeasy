# Veasy

Aplicação criada para ajudar jogadores de Clash Royale a encontrar informações atualizadas sobre decks e jogadores.
O objetivo é oferecer uma experiência simples e eficiente, reunindo dados relevantes do jogo em um só lugar.

---

## Principais ideias do projeto

* Fornecer uma forma rápida e intuitiva de pesquisar perfis de jogadores e seus decks.
* Buscar simplicidade, boa performance e uma interface direta.
* Arquitetura clara separando front-end e back-end para facilitar manutenção e evolução.

## Como configurar o projeto

1. **Instalação do back-end:**

   ```bash
   cd backend
   npm install
   ```
2. **Instalação do front-end:**

   ```bash
   cd ..
   npm install
   ```
3. **Configuração do arquivo .env:**

   * Copie `.env.example` para `.env`
   * Preencha as variáveis de ambiente necessárias
4. **Executar o projeto em modo desenvolvimento:**

   ```bash
   npm run dev
   ```
