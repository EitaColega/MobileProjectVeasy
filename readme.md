# Veasy  

Aplicação criada para ajudar jogadores de Clash Royale a encontrar informações atualizadas sobre decks e jogadores.  
O objetivo é oferecer uma experiência simples e eficiente, reunindo dados relevantes do jogo em um só lugar.

---

## Principais ideias do projeto  

A proposta do Veasy é fornecer uma forma rápida e intuitiva de pesquisar perfis de jogadores e seus decks.  
Buscamos simplicidade, boa performance e uma interface direta para que qualquer jogador encontre o que precisa sem complicações.  
A aplicação foi pensada com uma arquitetura clara, separando front-end e back-end para facilitar manutenção e evolução.

## Funcionalidades principais  

Acessar informações detalhadas de jogadores  
Consultar decks completos usados pelos jogadores  
Unir dados de forma organizada para facilitar comparações e estudos de estratégia
